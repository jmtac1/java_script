Iniciando os estudos DOM

DOM é uma interface de programação que representa uma página HTML como uma árvore de objetos, permitindo ao JavaScript acessar e manipular dinamicamente o conteúdo, estrutura e estilo da página

O navegador gera essa estrutura, facilitando a criação de sites interativos e responsivos.

Os métodos DOM (Document Object Model) mais comuns em JavaScript permitem selecionar, criar, modificar e remover elementos HTML. Os principais métodos incluem getElementById(), getElementsByClass(), getElementsByTagName(), getElementsByName(), querySelector(), querySelectorAll().
